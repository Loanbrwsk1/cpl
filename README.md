# cpl
A tool if you have enough to compile .c or .asm code by yourself

## Usage
```
Usage :
 cpl [-a/-c] FILE [FILE...] [OPTIONS]

Tool to compile code from a code .c or .asm.

Options :
  -a	To compile from ASM code
  -c	To compile from C code
  -o	To specify a filename for the output. By default, will use the first filename entered without the extension
  -x  To execute the code after compiling
  -h	Help
```

## Installation

Download the files, extract them and :
```
make install
```

## Uninstall

```
make uninstall
```
